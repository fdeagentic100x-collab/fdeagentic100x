          Course positioning

          This is not a course on "how to create multiple agents." It is an advanced engineering program on how to decide whether a multi-agent architecture is justified, decompose a complex business problem into specialized agents, design their communication and coordination mechanisms, engineer shared state and context, evaluate their collective behavior, and operate the resulting system as a production platform.

                        Write real code from Day 1

                        You get ready-to-run starter templates and a pre-configured sandbox before the first class. On Day 1 you run a single agent and a small agent team on the same task and compare them, which is the habit the whole course builds.

                        • Pre-configured Python sandboxLangGraph and other agent frameworks, the MCP SDK and an A2A-style message layer installed, with Redis and PostgreSQL for shared state.
                        • A starter template for every moduleTen templates that grow into your Enterprise Multi-Agent AI Platform, with tests and TODOs.
                        • Mock enterprise agents and toolsTransaction, KYC, policy, network and risk agents plus MCP tool servers for the fraud and AML scenario.
                        • Failure injectionSwitch on agent failures, lost messages, stale memory, loops and retry storms for the resilience challenge.
                        • Counterfactual evaluation harnessRun single agent vs multi-agent on the same golden dataset, with tracing and cost per task built in.
