            The FDE Six-Pillar Architecture Framework

            The program uses the six AWS Well-Architected pillars as a cross-cutting production framework: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization and Sustainability.

            Not just an AWS exerciseAWS officially defines these as the six pillars of its Well-Architected Framework. Google Cloud's current Well-Architected Framework similarly covers operational excellence, security, reliability, cost optimization, performance optimization and sustainability, with an explicit AI/ML perspective.
            Critical pointThese pillars do not live only in one architecture module. They appear in every major capstone.

            This is an overview. Details of this section are covered in depth during the program.

            Write real code from Day 1

            You get ready-to-run starter templates and a pre-configured sandbox before the first class. No setup weekend, no installing dependencies while the lecture moves on. Open it, run it, change it.

            • Pre-configured coding sandboxPython and TypeScript environments with the LLM, RAG, agent and MCP SDKs already installed.
            • A starter template for every moduleTwelve templates, each the scaffold for that module's production artifact, with tests and TODOs where you write the code.
            • Sample enterprise datasetsInsurance policies, claims, support tickets and product catalogues to build against from the first session.
            • Git-ready from the startEvery template is a repository, so your GitHub portfolio grows module by module.
            • Production checks built inEvaluation, tracing and security hooks are wired into the templates, so good habits start on Day 1.
